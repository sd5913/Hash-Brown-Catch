# Playtest plan for the 19 November review

Ask at least one person outside the development work to test the actual experience. A small group of 3–5 players is useful if feasible, but no completed sample is claimed here.

1. Give the participant the README and let them launch the game without coaching. Record setup difficulties.
2. Ask them to start a solo round and explain which objects to catch or avoid.
3. Observe movement, missed catches, hazard recognition, pause, exit and replay.
4. Ask them to explain score versus wallet coins and try the starter shop when they have sufficient coins.
5. Try Pixel Face using a built-in preset or a photo they choose voluntarily. Do not commit participant photos or saved portraits.
6. With another player, try VS and co-op. Observe whether basket bumps and relay scoring are understandable. Same-screen two-player testing should use a desktop keyboard.
7. Ask what the Hall of Fame represents and whether they would replay; record reasons, not assumed satisfaction.

Use IDs such as P01. Record date, device/browser, task, help needed, direct observation and a brief relevant comment. Avoid names or unnecessary personal information. Select a priority problem, implement a change with an owner, and retest it.
